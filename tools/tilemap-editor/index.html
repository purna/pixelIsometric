Writes an edit bundle you apply with npm run apply:map:edits. It updates the streaming sections, navigation map, minimap and canonical Tiled map. Then build and deploy the game with npm run build. Regenerating from OSM discards hand edits — export first.

HELP

Editing. Pick a layer, pick a tile from the palette, then paint. Drag to paint a run. Right-click erases. Fill floods the connected region of the matching tile, Pick grabs the tile under the cursor. Pan by dragging with the middle mouse button or space held; zoom with the wheel or the slider. Use the map toolbar: Move (H), Paint (B), Erase (E), Pick (I) and Fill (F). Picking a tile switches back to Paint. Undo / Redo restores brush strokes and region fills.

Layers. Ground is terrain (sea, surf, shingle, promenade, road, grass, pier deck). Structures holds solids (trees, walls, roofs, rides) and 0 means empty. Foreground holds non-colliding decoration.

Units. One tile = 10 m. 100×100 tiles = 1 km² per section. The world is Brighton: 600×200 tiles (6 km × 2 km); other towns: 200×200 tiles (2 km × 2 km), centred on the college. Each location has its own map and saved edits.

Names. Values inside the map files are 1-based Tiled GIDs; tile 0 is empty on Structures/Foreground.

Saving. Export → Download edit bundle → run npm run apply:map:edits -- edits.json. The editor autosaves to this browser as insurance.
